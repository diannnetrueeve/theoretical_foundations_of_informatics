## Задача
Консольная программа для обработки заявок сервисного центра. Срочные заявки обслуживаются раньше обычных.

## Формат входного файла
Файл `input.txt`, одна заявка на строку:
`номер;клиент;тип;категория;приоритет`

Типы: `ремонт`, `консультация`, `установка`.
Приоритеты: `обычная`, `срочная`.

## Запуск
Из каталога проекта выполните:
```bash
python main.py
```

## Структура программы
- `main.py` -тзагрузка и проверка данных, меню, обслуживание, отмена, статистика и отчёт.
- `data_structures.py` - собственные реализации узла, связного списка, очереди, стека и хэш-таблицы.
- `input.txt` - тестовые данные с корректными и некорректными строками.
- `report.txt` - создаётся при выборе пункта меню 9.

## Структуры данных
- `LinkedList`: `append`, рекурсивные `to_list` и `find`, `reverse`.
- `Queue`: `enqueue`, `dequeue`, `remove_value`.
- `Stack`: `push`, `pop`.
- `HashTable`: `set`, `get`; ключи проверяются на неизменяемый тип.

## Ссылочная модель
Каждый узел хранит значение и ссылку `next`. Добавление в хвост очереди выполняется через ссылку `tail`, удаление - изменением ссылок, без сдвига элементов. Для независимого копирования вложенных данных используется `copy.deepcopy`.

## Примеры
Корректно: `2001;Иванов Иван;ремонт;компьютер;обычная`
Некорректно: `abc;Иванов Иван;ремонт;компьютер;обычная`

## Обработанные ошибки
Отсутствие файла, неверное число полей, неверный или повторный номер, пустые обязательные поля, неизвестный тип/приоритет, пустые очередь и стек, отсутствие заявки, неверный пункт меню и пустые наборы для статистики.
